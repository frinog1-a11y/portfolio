# Автоматизация Windows: скрипты, задачи, CI

## Что это

Умение убрать ручную работу: PowerShell и Python-скрипты для пакетных операций, задачи
планировщика, службы, CI-пайплайны и самопроверяющиеся проверки вместо ручного контроля.

## Где подтверждено

- `cases/01-videokamera.md` — 18 инструментов в tools/ (диагностика сертификата, порта, ntfy,
  firewall, синтаксиса), ротация логов и ежедневная задача очистки через Планировщик задач,
  скрипт установки службы, обёртка запуска с окном UAC для агента без прав администратора.
- `cases/06-txt-to-docx.md` — 22 скрипта пакетной обработки: 194 PDF пересобраны с зеркальными
  полями, отчёт «найдено/обработано/ошибки», автоустановка зависимостей, 14 скриптов проверки
  результата, отменяемое переименование файлов.
- `cases/07-echelon-remote-pipeline.md` — 68 файлов автоматизации: доставка результатов на
  устройства, пробуждение ПК по сети, автологин, автозапуск локальных моделей, 32 скрипта
  диагностики окружения.
- `cases/02-normcontrol-kb.md` — CI на GitHub Actions: сборка, деплой, отдельная задача
  «из issue в заметку с помощью ИИ», скриптовый аудит ссылок и метаданных базы.
- `cases/04-echelon-beyond.md` — контракт «каждая задача оставляет результат» плюс механика
  доски задач, запускаемая одним cmd-файлом.

## Уровень

**Продвинутый.** Обоснование:

- Объём: 18 + 22 + 68 скриптов в трёх разных проектах, каждый — под конкретную операцию.
- Пакетность и объём обработки: 194 PDF и ~300 музыкальных файлов, обработанных скриптами,
  а не руками.
- Наличие самопроверок: 14 скриптов проверки полей/размеров/поворотов; 6 проверок в сервисе
  видеокамеры; аудит связей в базе знаний — то есть автоматизация не «сделал и надеюсь».
- Эксплуатационная зрелость: службы, Планировщик задач, ротация логов, восстановление после
  падения, обёртки для повышения прав.
- CI на двух разных площадках: GitHub Actions (база знаний) и локальные задачи/службы (Windows).
