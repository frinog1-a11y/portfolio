# Портфель кейсов — Израмор

Семь рабочих кейсов, собранных из реальных проектов на домашнем ПК: что сделано, зачем,
какими средствами и что из этого работает прямо сейчас. Все числа взяты из git-истории,
файлов проектов и скриптов; там, где данных нет, так и написано. Личные данные, пароли,
адреса приватных сетей и содержимое приватных документов в портфель не включены.

## Кто такой Израмор

Израмор — инженер-практик, который доводит свои бытовые и творческие задачи до работающих
систем: домашняя видеоняня с двусторонним звуком и автозапуском службой, публичная база знаний
по ЕСКД для супруги-нормоконтролёра и производственный контур игрового проекта, где ИИ-агенты
работают по контракту с доской задач, а визуальный стиль зафиксирован обученной LoRA.

## Чего ещё нет, но будет

Честный roadmap портфеля — по порядку полезности:

1. **Скриншоты и демо-видео.** Папка assets/ пока пуста: нет ни кадров интерфейса видеокамеры,
   ни скриншотов базы знаний и графа связей, ни записей прохождения мини-игры, ни картинок
   из арт-пайплайна. Это самое дешёвое и самое заметное улучшение.
2. **Читательская версия кейсов.** Сейчас это markdown с числами; для отправки людям без Git
   полезна одна страница или PDF-версия портфеля.
3. **Играбельное демо игры.** По Echelon Beyond нет ни одной рабочей сцены: только документация
   и ассеты. До первой сцены на Godot кейс остаётся «методом», а не «продуктом».
4. **Публичный репозиторий игры (возможно).** Требует обезличивания инфраструктурной
   документации (адреса устройств, приватная сеть) и отделения тяжёлых ассетов.
5. **Ссылка на музыку.** ~300 сгенерированных треков существуют локально; в портфеле нет
   ни одного прослушиваемого примера — нужен хостинг для нескольких отобранных треков.
6. **Метрики использования.** Не собираются: посещаемость сайта базы знаний, число задач,
   пришедших через форму, число событий движения, зафиксированных видеокамерой.
7. **Публикация портфеля.** Пока не выполнялась: репозиторий только локальный. Варианты —
   отдельный репозиторий с GitHub Pages или приватный архив для отправки по запросу.
8. **Выравнивание оценок.** Четыре навыка помечены «продвинутый» — при публикации стоит
   подтвердить их внешним взглядом (ревью кода сервиса и инструментов).

## Как читать этот портфель

- Начните с таблицы кейсов выше: «продукт» — то, что работает у людей, «метод» — подход,
  «инструмент» — утилиты, «демо» — публичная витрина.
- В каждом кейсе есть раздел «Метрики» (числа из источников) и «Что не получилось» —
  раздел с ограничениями считается самым важным.
- В файлах навыков раздел «Уровень» объясняет оценку цифрами, а не словами.
