# Артефакты портфеля (скриншоты, демо, превью)

Папка пуста на момент создания портфеля — здесь должны появиться подтверждающие материалы.
Правила простые:

- только обезличенные материалы: без паролей, адресов приватных сетей, имён людей и организаций;
- имена файлов с привязкой к кейсу: `01-videokamera-viewer.png`, `02-normcontrol-graph.png`;
- тяжёлое видео — отдельными ссылками (внешний хостинг), в git только превью и ссылка.

Что логично положить сюда первым (см. roadmap в корневом README):

| Кейс | Что снять |
|---|---|
| 01 Видеокамера | экран просмотра на телефоне, окно UAC-обновления, состояние службы |
| 02 База знаний | главная страница, карточка ошибки, граф связей, страница /add-note |
| 03 Мини-игра | 3–4 кадра боя, лорная записка, финальная анимация |
| 05 Арт и музыка | лучшие кадры меню, пример «до/после LoRA», 2–3 отобранных трека |
| 06 Вёрстка книг | разворот «до/после» с зеркальными полями |
| 07 Пайплайн | страница выдачи результатов на телефоне (адреса скрыть) |
